## À comprendre

1. **Le bilan du Gantt** : pour chaque tâche, début et fin prévus contre réels, le statut, et la cause de chaque écart ; la rotation des rôles à la fin de la S4.
2. **Reproductibilité de la remise** : un clone propre, `pip install -r requirements.txt`, `python -m pytest` doit passer ; les notebooks s'exécutent de bout en bout ; les résultats LLM sont fournis dans `resultats/` avec la version du modèle.
3. **Honnêteté du bilan** : ce qui n'a pas été fait ou n'a pas marché se dit ; les limites de chaque résultat s'écrivent dans le rapport.
